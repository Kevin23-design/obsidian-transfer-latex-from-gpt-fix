## 1. 소개
이 프로젝트는 작동하지 않던 버그를 수정한 [이 프로젝트](https://github.com/xixia123/obsidian-transfer-latex-from-gpt)의 수정 파일입니다. 원작자가 오랫동안 유지 보수를 하지 않았기 때문에 먼저 이 플러그인을 공개합니다. 원작자가 유지 보수를 재개하면 이 프로젝트의 유지 보수는 중단됩니다.
이 프로젝트의 목표는 ChatGPT 답변의 LaTeX 수식을 Obsidian이 인식하고 올바르게 렌더링할 수 있는 마크다운 형식으로 변환하는 것입니다. 이 도구는 사용자가 Obsidian 노트에서 수학 수식을 편리하게 사용하여 학습 효율성과 연구 품질을 향상시키는 데 도움이 됩니다.

## 2. 설치
1. 커뮤니티 플러그인에서 `Transfer Latex from GPT` 플러그인을 직접 설치합니다.
2. 또는 [GitHub 리포지토리](https://github.com/Kevin23-design/obsidian-transfer-latex-from-gpt-fix)에서 플러그인 패키지를 다운로드하여 수동으로 설치합니다.
