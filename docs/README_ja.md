## 1. 紹介
このプロジェクトは[このプロジェクト](https://github.com/xixia123/obsidian-transfer-latex-from-gpt)の修正版であり、機能しなかったバグを修正しています。元の作者が長期間メンテナンスしていないため、このプラグインを先にリリースしました。もし元の作者がメンテナンスを再開した場合は、こちらのメンテナンスを停止します。
このプロジェクトの目的は、ChatGPTの回答内のLaTeX数式をObsidianが認識し、正しくレンダリングできるMarkdown形式に変換することです。このツールは、ユーザーがObsidianのノートで数学の数式を簡単に使用できるようにし、学習効率と研究の質を向上させます。

## 2. インストール
1. コミュニティプラグイン市場から直接`Transfer Latex from GPT`プラグインをインストールします。
2. または、[GitHubリポジトリ](https://github.com/Kevin23-design/obsidian-transfer-latex-from-gpt-fix)からプラグインパッケージをダウンロードして手動でインストールします。

## 3. 使用方法
**注意**: 使用する前に、Obsidianのエディタ設定で「HTMLの自動変換」オプションをオフにしていることを確認してください。そうでない場合は、ChatGPTの回答を貼り付ける際にプレーンテキスト形式を使用する必要があります。
