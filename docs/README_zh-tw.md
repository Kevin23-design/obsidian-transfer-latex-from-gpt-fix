## 1. 介紹
本項目是對[該項目](https://github.com/xixia123/obsidian-transfer-latex-from-gpt)的修復，修復了其無法運作的bug。由於原作者長時間沒有維護，所以先發布該外掛，如果原作者恢復維護，我會停止維護。
本項目的目標是將ChatGPT回答中的LaTeX公式轉換為Obsidian能夠識別且正確渲染的Markdown格式。此工具幫助使用者在Obsidian筆記中便捷地使用數學公式，提高學習效率與科研質量。

## 2. 安裝
1. 透過社群外掛市場直接安裝`Transfer Latex from GPT`外掛。
2. 或者從[GitHub倉庫](https://github.com/Kevin23-design/obsidian-transfer-latex-from-gpt-fix)下載外掛包並手動安裝。

## 3. 使用說明
**注意**：使用前，請確保在Obsidian編輯器設定中關閉「自動轉換HTML」選項。否則，貼上ChatGPT的答案時，應使用純文字格式。
